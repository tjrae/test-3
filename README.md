# Tyler Jacob Raeside - Technology Portfolio

A simple four-page HTML5 website created for CIS 124 Web Development I.

## Pages
- `index.html` - About me, skills, and interests
- `resume.html` - Summary, education table, employment history, skills, and activities
- `projects.html` - Web development and Linux coursework, plus extracurricular accomplishments
- `contact.html` - Email, phone, location, and a basic email-app contact form

## How to view
Open `index.html` in a browser and use the navigation links to explore the pages.

The website uses semantic HTML5 with `header`, `nav`, `main`, and `footer` elements. No CSS or JavaScript is required for this first phase.

The contact form opens the visitor's email app; it does not send messages by itself or store submissions.
